# 📊 QC Board — ระบบกระดานส่งงานคอนเทนต์เพจสุขภาพ & ตรวจคำผิดอัตโนมัติ

ระบบกระดานส่งงานสไตล์ Trello สำหรับทีมคอนเทนต์ (ออกแบบมาสำหรับเพจสุขภาพโดยเฉพาะ) พร้อมระบบดักจับความผิดพลาดครบวงจร:

- **7 ขั้นตอนการทำงานจริง:** `1. ไอเดีย (รอตรวจ)` ➡️ `2. เขียนบท` ➡️ `3. บทเสร็จ (รอตรวจ/ปรับแก้)` ➡️ `4. บทสมบูรณ์` ➡️ `5. ตัดเสร็จ (รอตรวจ)` ➡️ `6. รอลง (ตั้งเวลาโพสต์)` ➡️ `7. ลงแล้ว (เช็คช่อง 1, 2, 3...)`
- **ดึง Thumbnail ข่าวอัตโนมัติ (`/api/extract-news`):** วางลิงก์ข่าวเพื่อดึงรูปปกข่าว (`og:image`) และหัวข้อข่าวขึ้นปกการ์ดทันที
- **เขียนบทเพจสุขภาพอัตโนมัติจากลิงก์ข่าว:** เลือกมุมสุขภาพได้ 5 มุม × สไตล์การเล่าเรื่อง 5 สไตล์
- **ตรวจคำผิดภาษาไทย 3 ชั้นอัตโนมัติ:** ตรวจคำสะกดผิด/ศัพท์สุขภาพ, คำซ้ำติดกัน, และคำผิดบริบทประโยคคำถาม

## 🚀 วิธีนำขึ้น GitHub และ Deploy บน Vercel (ฟรี)

1. อัปโหลดโค้ดขึ้น GitHub Repository ของคุณ
2. เข้าเว็บ [vercel.com/new](https://vercel.com/new) แล้วกด **Import** โปรเจกต์จาก GitHub
3. กดปุ่ม **Deploy** ได้ทันที (ไม่ต้องตั้งค่า Build Command เพิ่มเติม เพราะมีไฟล์ `vercel.json` และ Serverless Functions ในโฟลเดอร์ `/api` เตรียมไว้ให้ครบแล้ว)
